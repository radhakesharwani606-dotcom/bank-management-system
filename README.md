# 🏦 Bank Management System:-

A Python-based Bank Management System developed using Object-Oriented Programming (OOP) concepts and JSON file handling.

## 📌 Features:-
- Create New Account
- Deposit Money
- Withdraw Money
- Check Account Details
- Update  Bank Details using Account and PIN verification
- Delete Bank Account

## 🛠️ Technologies Used:-
- Python
- Object-Oriented Programming (OOP)
- JSON
- VS Code
- Git & GitHub
